# Edit 1 Job Board

Day-to-day shift board for Edit 1: jobs, suites, editors, tasks and bookings.

A static web app (plain HTML/CSS/JS, no build step) hosted on GitHub Pages,
released through stages: Dev → Alpha → Staging → Production.

| Stage | Address |
|---|---|
| Dev | https://thedodgykiwi.github.io/Edit1-Jobs-Board/dev/ |
| Alpha | https://thedodgykiwi.github.io/Edit1-Jobs-Board/alpha/ |
| Staging | https://thedodgykiwi.github.io/Edit1-Jobs-Board/staging/ |
| Production | https://thedodgykiwi.github.io/Edit1-Jobs-Board/ |
| Pipeline (what's where) | https://thedodgykiwi.github.io/Edit1-Jobs-Board/pipeline/ |

Set up from the app starter in [app-playbook](https://github.com/Thedodgykiwi/app-playbook),
which also provides the shared deploy and the promote skill.

Run locally: `python3 -m http.server 8080` and open http://localhost:8080.
