# Edit 1 Job Board

Day-to-day shift board for Edit 1: jobs, suites, editors, a supervisor
checklist and job history search. One shared board for the team, opened by
signing in with an approved Google account; data is saved in Cloud Firestore.

- Dev: https://thedodgykiwi.github.io/Edit1-Jobs-Board/dev/
- Production: https://thedodgykiwi.github.io/Edit1-Jobs-Board/

Rebuilt from the original ChatGPT Sites version (`reference/`). How it's put
together and how to work on it: `CLAUDE.md`.
